## 🃏 Proyecto principal: Wijutopia
Plataforma web de una tienda real de juegos de cartas coleccionables de Trujillo — [wijutopia.com](https://wijutopia.com)

- Catálogo, tienda en línea, panel del personal y atención al cliente (React, Node.js, PostgreSQL).
- Desplegada en la nube con servicios gratuitos (Cloudflare, Render y Neon): su único costo es el dominio.
- Bot de atención por WhatsApp, procesos modelados en BPMN y automatizados con Camunda 7 y n8n.
- Tableros en Power BI y Metabase con un usuario de solo lectura.
- **526 pruebas automáticas** y 94 pull requests revisados. *(El código es privado; el sitio de presentación está en [wijutopia-marketing](https://github.com/minombreesandersson-dot/wijutopia-marketing).)*
